# IT Management Service Application

A lightweight single-page web app for IT teams to manage:

- Team members
- User duties and responsibilities
- Tasking assignments
- Help desk tickets
- Computer inventory (owner, hostname, IP address, and MAC address)

## Quick Start

Open `index.html` in a browser.

Demo credentials:

- Username: `admin`
- Password: `password123`

## Data Storage

The app uses browser `localStorage` for records and `sessionStorage` for login state.
